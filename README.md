技术架构与音视频能力

典型架构采用前后端分离、多端适配、模块化与插件化设计。前端可使用UniApp、Taro、原生小程序、Flutter或React/Vue；后端可采用PHP、Java、Node.js、Go等语言。数据库使用MySQL存储用户、课程、订单、权限等核心数据；Redis用于缓存、会话、排行榜、验证码与队列；消息队列处理转码回调、短信、推送、订单超时、分账等异步任务；Elasticsearch支持课程与内容全文检索；对象存储与CDN承载图片、音频、视频与直播回放。

音视频是技术关键。音频点播需支持上传、转码、压缩、试听、倍速、续播、后台播放与防盗链。视频点播需支持多清晰度转码、HLS/DASH切片、封面、字幕、水印、跑马灯、防录屏、加密与CDN分发。直播需支持RTMP推流、RTC低延迟互动、HLS回放、连麦、白板、聊天、点赞、打赏、商品挂载与录制。源码应提供统一媒体管理，避免图文、音频、视频、直播各自为政。
